Key Implementation Details:

Problem Statement:
  ~430 Figma bindings are using primitive tokens (e.g., size/space/12, size/font/40)
  instead of semantic tokens, violating the design system rule:
  "Bind to Semantic. Never to Primitives."

Token System Architecture:
  1. Primitives (285 tokens) → hidden, unscoped, raw values
  1b. Palette (19 tokens, 6 modes) → palette-specific aliases
  2. Semantic (186 tokens, 2 modes) → THE TARGET TIER ✓
  3. Component (56 tokens) → component-specific
  4. Canvas (4 tokens) → canvas-specific

Known Issues to Address:
  - 12px gaps (16 uses) → should map to space/3xs (8) or space/2xs (16)
  - 40px font sizes (51 uses) → should map to appropriate type scale token
  - Off-scale values need MANUAL review flag

Confidence Score System:
  - HIGH: Exact match to semantic token value
  - MEDIUM: Nearest neighbor mapping
  - MANUAL: Off-scale value, requires human decision
  - LOW: Ambiguous mapping

Expected Outputs:
  1. analysis.json - Category breakdown of primitive usage
  2. migration-map.json - Primitive→Semantic mappings with confidence
  3. migration-report.md - Human-readable summary and recommendations
  4. migration-figma.json - DTCG format for Figma import
  5. manual-review.json - Flagged items requiring human review

Acceptance Criteria:
  ✓ Tool identifies ~430 primitive bindings
  ✓ Each binding gets suggested semantic replacement with confidence score
  ✓ Ambiguous mappings (12px gaps, 40px fonts) flagged for manual review
  ✓ Report shows: total bindings, auto-mappable count, manual-review count, category breakdown
  ✓ Tool generates Figma-importable migration file (DTCG format)
  ✓ Post-migration, tokens-to-css.mjs produces identical CSS for currently-correct bindings
  ✓ Migration reduces primitive binding count from ~430 to near zero
